# UI仕様書 (UI_SPECIFICATION.md)

## 概要
本ドキュメントは、適応型学習システムのUI仕様を定義する。NotebookLMの構成を参考に、3パネルレイアウトを採用する。

## 1. レイアウト構成

### 1.1 パネル比率
- **初期設定**: 1.5:5:3.5 (左:中央:右)
- 各パネルはドラッグでリサイズ可能（最小/最大制限あり）

### 1.2 パネル配置
```
┌──────────┬─────────────────────────┬────────────────┐
│ 左 15%   │       中央 50%          │    右 35%      │
│ ノード   │    コンテンツパネル     │   チャットUI   │
│ 構成UI   │                         │                │
└──────────┴─────────────────────────┴────────────────┘
```

### 1.3 レスポンシブ対応
- **デスクトップ (≥1024px)**: 3パネル表示
- **タブレット (768-1023px)**: 中央+右の2パネル（左はオーバーレイ）
- **モバイル (<768px)**: 1パネル表示（タブ切替）

---

## 2. 左パネル: ノード構成UI

### 2.1 機能
- フォルダ/ツリー構造での思考構造表示
- ノードの展開/折りたたみ
- ノード選択 → 中央パネル連動

### 2.2 ノードタイプ
| タイプ | アイコン | 説明 |
|--------|----------|------|
| purpose | 🎯 | 目的ノード |
| option | 📋 | 選択肢ノード |
| resource | 🔗 | 外部リソースノード |
| thought | 💭 | 思考ノード |

> **注**: アイコンは将来的にSVGアイコンに置き換え可能

---

## 3. 中央パネル: コンテンツパネル

### 3.1 表示モード
- **デフォルト**: タブ切替
- **同時表示**: 状況に応じて複数コンポーネント共存

### 3.2 同時表示パターン
- 選択肢UI + カスタムページ
- 選択肢UI + ノードグラフ
- ドキュメント + 選択肢UI
- その他の組み合わせ（状況依存）

### 3.3 コンテンツ種類

#### カスタムページ
- AIが生成したHTML/CSS/JS
- サンドボックス内で安全に実行

#### 選択肢UI
- 選択肢カード表示
- **条件付きソート/フィルタUI**: チャット応答より効率的な場合のみ動的に追加

#### ノードグラフ
- ノード間関係の可視化
- **ホバー時に生成ドキュメント（説明）を表示**

#### 生成ドキュメント
- **全ノードの情報を一覧表示**
- ユーザー入力からLLMが解析した情報の投影
- ノードごとの構造化表示
- ※ 「選択したノードのみ表示」ではない

### 3.4 状況依存の共存表示ルール

迷子状態（M0-M5）に応じて、表示するコンポーネントを動的に決定する。

| 迷子状態 | 意図検出 | 選択肢 | グラフ | sandbox | 備考 |
|---------|---------|-------|-------|---------|------|
| M0 | ✅ | △ | ❌ | ❌ | 空間縮小段階 |
| M1 | ✅ | ✅ | △ | ❌ | グラフは状況依存 |
| M2 | ✅ | ✅ | ✅ | ❌ | 思考整理にグラフ必要 |
| M3 | ✅ | ✅ | ✅ | △ | 判断軸形成中 |
| M4 | ✅ | ✅ | ✅ | ❌ | 問いの設計が重要 |
| M5 | ✅ | ❌ | △ | ❌ | 構造-目的接続確認 |
| RESOLVED | ✅ | ✅ | ✅ | ✅ | 迷子状態解消 |

**凡例**: ✅=生成, ❌=生成しない, △=状況依存

> **重要**: sandboxは判断軸が確立された場合のみ生成を検討。安易な生成は思考の介入につながる。

---

## 4. 右パネル: チャットUI

### 4.1 機能
- メッセージ履歴表示
- 入力フォーム
- **展開/折りたたみ機能**

### 4.2 LLM解析（内部処理）
- **暗黙的ソート優先順位**: 会話コンテキストからLLMが解析
- **暗黙的フィルタ条件**: 会話の節々から意図を検出
- ※これらはUI表示せず、システム内部で処理

---

## 5. 禁止事項

### 5.1 UI上での禁止
- ソート/フィルタUIの常時表示（条件付きで動的追加のみ許可）
- 「おすすめ」「重要」などのハイライト
- 選択肢への優先度表示

### 5.2 設計原則
- 思考の代行禁止
- 判断の誘導禁止
- 構造の投影のみ許可

---

## 6. インタラクション仕様

### 6.1 ノード選択時
1. 左パネルでノード選択
2. 中央パネルに関連コンテンツを表示
3. ノードグラフでハイライト

### 6.2 チャット入力時
1. ユーザー入力を受信
2. APIで構造生成
3. ノード構成ツリーを更新
4. 中央パネルにコンテンツを投影
5. LLMがソート/フィルタ意図を解析

### 6.3 ノードグラフホバー時
1. ノードにカーソルを合わせる
2. 生成ドキュメント（説明）をツールチップとして表示
