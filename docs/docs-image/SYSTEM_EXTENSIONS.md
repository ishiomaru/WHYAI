# システム拡張機能仕様書 (SYSTEM_EXTENSIONS.md)

## 概要
本ドキュメントは、`CONCEPT_NOTES.md` で定義されたコア適応学習モデルを補完するために実装された、システム固有の拡張機能について定義する。これらの機能は、抽象的な「構造投影」や「外部リソース収集」という概念を、具体的な技術実装として具現化したものである。

## 1. サンドボックス生成機能 (Sandbox Projection)

### 概要
概念上の「Layer A (構造空間)」の拡張として、学習者が到達した理解（迷子状態解消 = RESOLVED）を、実行可能な「成果物」として可視化する機能。

### 実装詳細
*   **場所**: `src/lib/learner-support-service.ts` (`generateSandboxCode`)
*   **トリガー**: 迷子状態が `RESOLVED` (解消) と判定された場合のみ生成される。
*   **出力**: 単一のHTMLファイルとして完結する、HTML / CSS / JavaScript のコードセット。
*   **役割**:
    *   単なるテキストの要約ではなく、学習した構造（ノード間の関係や階層）をインタラクティブなUIとして投影する。
    *   ユーザーが「自分の思考が形になった」と感じられるフィードバックループを提供する。

## 2. 外部検索サービス実装 (Web Search Integration)

### 概要
概念上の「外部リソース収集」を、具体的なWeb APIを用いて実装したもの。AIの「解釈」を介さず、生の情報を構造化の素材として提供する。

### 実装詳細
*   **場所**: `src/lib/web-search-service.ts`
*   **プロバイダ**:
    *   **DuckDuckGo Instant Answer API**: ユーザーのプライバシーを保護しつつ、APIキーなしで検索結果を取得するために採用。
    *   **Wikipedia API**: 定義的・網羅的な情報の補完として使用。
*   **制約 (AI Role Limitation)**:
    *   AIは検索クエリ（キーワードと広さ）の生成のみを行い、検索結果の「順位付け」や「選別」は行わない（APIの返却順を尊重）。
    *   取得したコンテンツは、意味的な要約を行わず、固定長の「チャンク」として機械的に処理される。

## 3. セキュリティバリデーション (Security Validation)

### 概要
自動生成されるサンドボックスコードが、ユーザー環境で安全に実行されることを保証するための厳格なフィルタリング機構。

### 実装詳細
*   **場所**: `src/lib/learner-support-service.ts` (`validateSandboxCode`)
*   **禁止事項 (Forbidden Patterns)**:
    *   **外部通信**: `fetch`, `XMLHttpRequest` などの通信APIの使用を禁止（データの流出防止）。
    *   **外部スクリプト**: 外部CDNやスクリプトタグによる他社コードの読み込みを禁止。
    *   **動的実行**: `eval` などの任意コード実行関数の使用を禁止。
*   **動作**: 違反パターンが検出された場合、該当コードは無害化（ストリップ）されるか、警告コメントに置き換えられる。これにより、AIが予期せず悪意あるコードを生成した場合でも、ユーザーへの被害を防ぐ。
